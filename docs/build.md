# Сборка и настройки проекта

## Build Settings
- **Платформа**: PC, Mac & Linux Standalone (или WebGL, в зависимости от настроек).
- **Сцены**: SampleScene добавлена в список сцен для сборки (Scenes In Build).

## Package Manager
- **Input System** — используется для обработки ввода с клавиатуры.
- **2D Sprite** — для работы с двумерной графикой.
- **TextMeshPro** — для качественного отображения текста в UI.
- **Cinemachine** — для плавного слежения камеры за игроком.

## Структура папок
- `Assets/IndieMarc` — основной контент шаблона (сцены, скрипты, префабы, спрайты).
- `Assets/Scenes` — файлы сцен.
- `Assets/Scripts` — пользовательские скрипты.
- `ProjectSettings` — настройки проекта Unity.

## Ассеты
- **Спрайты**: Пиксельная или векторная 2D-графика для персонажа, платформ и фона.
- **Звуки**: Фоновые звуки и звуковые эффекты (прыжок, сбор предметов).
- **Размер проекта**: Около 50–100 МБ (без учета библиотеки Library, которая исключена через .gitignore).
