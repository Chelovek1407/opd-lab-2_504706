# Структура проекта

## Сцены
- **SampleScene** — основная игровая сцена. Содержит объект игрока (Player), камеру (Main Camera) и платформы уровня. 
- **PlatformerScene** (если применимо) — альтернативная сцена с платформерным геймплеем.

## Объекты на сцене
- **Main Camera** — камера, следит за игроком (компонент Cinemachine или стандартный скрипт).
- **Player** — объект игрока. Состоит из компонентов: Transform, Sprite Renderer, Rigidbody2D, BoxCollider2D, Animator, скрипт PlayerCharacter.
- **EventSystem** — отвечает за обработку событий UI.
- **Grid / Tilemap** — используется для отрисовки уровня.
- **Префабы платформ и препятствий** — экземпляры префабов, расставленные по сцене.

## Скрипты
- **PlayerCharacter.cs** — управляет движением игрока (бег, прыжки, гравитация).
- **CameraFollow.cs** — заставляет камеру следовать за игроком.
- **LevelManager.cs** — управляет логикой уровня (например, возрождение игрока или завершение уровня).
- **ItemCollector.cs** — отвечает за сбор бонусов/монет.
