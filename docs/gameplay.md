# Геймплей и физика

## Физические параметры
- **Гравитация**: Стандартная для Unity 2D (Gravity Y = -9.81). Настраивается в Project Settings -> Physics 2D.
- **Масса игрока**: 1 (по умолчанию в Rigidbody2D). Влияет на взаимодействие с физическими объектами.
- **Физические материалы**: Стандартные (Friction = 0.4, Bounciness = 0), чтобы игрок не скользил и не подпрыгивал без команды.

## Префабы
- **Препятствия/Платформы**: Префабы платформ (Platform), на которых стоит игрок. Имеют компонент BoxCollider2D.
- **Враги**: Префабы врагов (Enemy). Имеют скрипт, наносящий урон игроку при столкновении.
- **Бонусы**: Префабы монет или других собираемых предметов. Содержат компонент Collider2D с галочкой Is Trigger.

## UI
- **Canvas** — основной холст интерфейса.
- Элементы: Текст (счетчик очков), кнопки (перезапуск уровня, меню).

## Влияние на сложность
- **Гравитация**: Увеличение параметра Gravity Y делает прыжки короче и резче, усложняя платформинг.
- **Масса игрока**: Изменение массы влияет на инерцию и скорость падения.
- **Скорость перемещения**: Настраивается в скрипте PlayerCharacter (параметр Move Speed). Увеличение делает игру быстрее и сложнее.
